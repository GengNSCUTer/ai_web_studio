## 二、风险说明

- 系统支持接入在线 API，也支持接入本地模型。部署时不能仅凭“使用本地模型”判断资料不会离开本地环境。
- 核对依据明确指出：**文档解析与联网工具仍可能外发资料**。因此，即使模型侧采用本地部署，文档解析、联网工具等环节仍可能构成资料外发风险。
- **不能将“自部署”或“本地模型”等同于“必然不出域”**。是否出域取决于完整链路，包括模型调用方式、文档解析组件、联网工具及网络出口配置等。
- 在线 API 接入属于需要重点核查的链路；本地模型部署同样需要核查周边组件是否存在外发行为。

## 三、部署核查建议

建议在部署前核实以下事项：

1. 在线 API 与本地模型的实际调用路径及网络出口。
2. 文档解析组件是否会将文件、片段或解析结果发送至外部服务。
3. 联网工具是否默认启用、是否可关闭、是否限制外发内容与目标地址。
4. 日志、缓存、临时文件及第三方依赖是否可能携带或外发资料。
5. 部署配置中是否存在未明示的外部端点或自动上传行为。

## 四、结论

基于现有授权资料，可确认系统同时存在在线 API 与本地模型接入方式，且文档解析与联网工具仍可能外发资料。因此，部署风险说明应表述为：**自部署或本地模型部署不能保证资料必然不出域，必须对完整链路进行核查。** 现有资料不足以证明任何部署方式可确保资料完全不出域。

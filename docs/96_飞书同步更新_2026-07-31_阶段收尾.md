# 2026-07-31：五轮受限 Agent、评测与记忆治理阶段收尾

同步 Chat 的 Tool Workflow 已调整为最多五轮 `plan -> execute -> observe`。五轮是硬上限，不是开放式自主循环：每轮仍受单 Plan 调用限额、Schema、凭据、工作区、Skill allowlist、风险、取消和超时约束；第五轮继续请求会记录 `max_rounds_reached`，低风险只读长任务需显式提交 Durable Tool Run。

RAG 侧已有 Eval Set、Chunk/Document Ground Truth、Hit@K、MRR、Context Precision/Recall、配置快照、降级与耗时记录。本轮补齐 Skill/Tool Gold Set 的批量聚合评分，基于真实捕获的 Planner Plan 与 execution status 计算 Skill Recall@3、Tool Recall、Planner/参数正确率、任务成功率和 p50 延迟；不会自动调用付费模型，也不会把未运行样本计为成功。

## 已实现内容

- 新增用户级工具凭证表 `user_tool_credentials`。
- 新增工作区工具开关表 `workspace_tool_settings`。
- 新增工具配置 API：
  - `GET /api/tools/settings`
  - `PATCH /api/tools/credentials/{provider_key}`
  - `POST /api/tools/credentials/{provider_key}/test`
  - `PATCH /api/tools/workspaces/{project_id}/{tool_key}`
- 设置面板新增 `工具与集成` tab。
- 支持 Tavily / 高德 provider 的 API Key 配置、掩码显示、连接测试、启用/禁用。
- 支持当前工作区按具体工具启用/禁用。
- 工具执行链路接入 `ToolCredentialResolver`，执行前检查工作区工具开关和 provider 凭证。
- Tool Trace 只记录 `credential_source`，不记录完整 API Key。

## 当前凭证优先级

```text
工作区禁用具体 tool_key
-> 用户显式禁用 provider
-> 用户 API Key
-> 后端 .env fallback
-> missing/skipped
```

## 当前限制

- 工具配置仍在设置弹窗中，还没有拆成独立设置页。
- API Key 第一版数据库明文保存；接口只返回掩码，日志和 Tool Trace 不记录完整 key。后续需要增加加密存储。
- 工具导入目前是内置 registry，不支持自定义 HTTP 工具、MCP Client、插件市场。

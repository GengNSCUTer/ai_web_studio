# 2026-05-19 深度思考与联网搜索 MVP 更新

本次把 `深度思考`、`联网搜索`、`外部信息源` 从规划推进到第一版可用实现。

## 已完成

- 前端输入区新增 `联网搜索` 和 `深度思考` 开关。
- 后端新增结构化 NDJSON 流：`tool_sources`、`reasoning_delta`、`answer_delta`、`done`。
- 前端支持回答正文和思考过程分离展示，思考过程默认折叠。
- 前端支持外部来源卡片展示，网页来源可点击跳转。
- 后端接入 Tavily Search，作为网页实时信息来源。
- 后端接入高德天气，作为天气类问题专用工具。
- 后端新增规则级 Tool Router：天气走高德，地图类暂回退网页搜索，其他实时信息走 Tavily。
- 外部信息源注入 Prompt Builder，并进入上下文治理统计。
- `messages` 表新增 `reasoning_content` 和 `external_sources` 字段，用于保存思考过程和外部来源。
- 新提问、重新生成、编辑上一条用户消息并重答都已接入结构化流。
- `.env.example` 增加 Tavily / 高德 / 工具超时配置占位，真实 key 只保存在 ignored `.env`。

## 验证结果

- 后端编译通过：`python -m compileall app`。
- 前端构建通过：`npm run build`。
- 高德天气真实调用通过：`今天广州天气怎么样` 返回 1 个 weather 来源。
- Tavily 搜索真实调用通过：`LangChain 最新版本有什么变化` 返回 6 个 web 来源。

## 当前边界

- 当前不是完整 Agent，不做多轮自主工具循环。
- 当前 Tool Router 是规则级，不是 LLM Router。
- 当前没有独立 Tool Registry 和工具调用 Trace 表。
- 高德地图 POI / 路线 / 地址解析未接入。
- Tavily / 高德 API Key 当前来自后端 `.env`，还不能由用户在设置页配置。

## 下一步建议

1. 增加工具调用过程事件：`tool_plan`、`tool_call_start`、`tool_call_end`。
2. 拆分 `ExternalContextService`，形成 Tool Registry、Tool Router、Tool Executor。
3. 增加工具调用 Trace 持久化。
4. 接入高德地图 POI / 路线 / 地址解析，只做只读工具。
5. 回到 P3 工作区知识库索引和跨历史附件召回。

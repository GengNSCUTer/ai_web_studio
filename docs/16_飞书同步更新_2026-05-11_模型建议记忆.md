# 2026-05-11 更新：模型建议记忆 v1

## 本次完成

- 完成“模型建议记忆”第一版。
- 用户可以在长期记忆面板中从当前会话提取候选长期记忆。
- 候选记忆不会自动写入数据库，必须由用户点击保存后才会进入长期记忆库。

## 后端变化

- 新增 `POST /api/memories/suggest`。
- 接口输入：
  - `conversation_id`
  - `max_candidates`
- 后端读取：
  - 当前会话最近消息
  - 已有长期记忆
  - 当前用户 provider/model 配置
- 调用当前 provider/model 生成 JSON 候选记忆。
- 后端解析并规范化候选记忆，只返回前端，不直接写库。

## 前端变化

- 长期记忆设置分区新增：
  - “从当前会话提取建议记忆”
  - 候选记忆卡片
  - 保存候选
  - 忽略候选

## 当前边界

- 不自动保存记忆。
- 暂不做复杂冲突检测。
- 暂不记录候选来源消息。
- 如果模型返回非 JSON 或无有效候选，则显示为空建议。

## 下一步建议

- 增加记忆去重和冲突检测。
- 给记忆增加来源会话 / 来源消息追踪。
- 后续结合附件索引化，做 Artifact Memory。

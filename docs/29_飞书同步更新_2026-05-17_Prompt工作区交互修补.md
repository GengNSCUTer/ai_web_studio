# 飞书同步更新：Prompt / 工作区交互修补

## 本次修补

### 1. Prompt 模板语义拆分

- `模板可见范围`：只表示模板归属全局或某个工作区，用于分类和展示。
- `应用目标`：才表示真正生效位置，可以选择写入全局 System Prompt 或任意指定工作区 System Prompt。
- 这样避免“模板属于某个工作区”被误解为“已经自动成为该工作区 System Prompt”。

### 2. 工作区侧栏收敛

- 左侧工作区区域压缩为轻量选择器。
- 新建和设置入口改为小型操作按钮，减少对历史会话列表空间的挤占。
- 工作区默认模型和 System Prompt 仍在工作区设置弹窗中维护。

### 3. 聊天输入框深色模式修复

- 移除输入区底部无效状态标签。
- 聊天 composer 使用独立 `chat-composer` 样式。
- 深色模式下对 composer textarea 做透明背景例外处理，避免全局 dark 表单背景把输入框渲染成突兀矩形。

## 验证

- `npm run lint` 通过。
- `npm run build` 通过。

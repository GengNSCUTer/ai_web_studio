# 2026-08-03：项目实现全景、五轮口径与简历更新

## 本次同步

本地新增权威文档：`docs/100_项目当前实现全景与面试口径_2026-08-03.md`。它统一记录当前定位、六条主链、权威参数、安全边界和面试讲稿；后续与代码不一致的历史学习笔记以该文档和源码为准。

## 当前定位

项目定位为面向个人与小团队的本地知识工作平台，服务论文、技术文档和项目资料的组织、检索、审阅与受控行动。当前不表述为已商业上线、涉密客户交付、无限自主 Agent 或任意高风险动作可恢复。

## 六条主链

1. 文档索引与混合 RAG：Outbox + Redis Stream + Worker 完成解析、Parent-Child Chunk、Embedding、pgvector、持久化 BM25、RRF、可选 Rerank、来源追踪和 generation CAS 发布。
2. 流式 Chat：Prepare/Stream 状态机先保存 Assistant 锚点，再返回 answer、reasoning 和 Tool 事件，统一收口完成、取消、失败和 Provider 超时。
3. 记忆管理：滚动摘要按边界增量压缩；长期记忆异步提炼为 pending 候选，经敏感、时效、置信度、重复和冲突检查后由用户审核激活。
4. Context/Token：按 System、项目指令、摘要、近期历史、当前问题、记忆、附件、RAG、Tool evidence 分层组装，预留输出并优先裁剪旧历史；稳定前缀记录 prefix hash。
5. Tool/Skill：代码负责候选召回、Schema、ACL、凭据、风险、SSRF 和预算，LLM 只生成候选内 ToolPlan，Executor 执行 MCP/HTTP 并处理不可信 Observation；Skill 使用 manifest digest、版本锁和显式启用/升级/回滚。
6. Durable/权限：低风险只读长任务使用 AgentRun/Step/Checkpoint、Outbox、Lease/Fencing、重试、DLQ、受控重放和对账；文件写入使用 PatchDraft、用户审批、一次性 challenge 和 FileRevision CAS。

## 关键参数与边界

- 同步 Chat 的 Tool Workflow 最多 5 轮 `plan -> execute -> observe`。
- 每份 ToolPlan 最多 5 次调用；第 5 轮继续请求会记录 `max_rounds_reached` 并终止。
- Durable Runtime 只接收低风险只读 Tool DAG，不等于所有同步 Chat 都能从进程崩溃处恢复。
- 不开放 Bash、Shell、SQL、删除文件、任意本机写、支付、邮件、外部发布和任意 HTTP 写。
- Prompt Cache 仅实现稳定前缀、prefix hash 和 vLLM/OpenAI-compatible 兼容观测，不宣称 Provider 官方缓存命中成果。

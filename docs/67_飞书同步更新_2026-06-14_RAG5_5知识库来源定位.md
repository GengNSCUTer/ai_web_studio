# 2026-06-14 RAG-5.5 知识库来源定位

## 本轮完成

本轮完成 `RAG-5.5`：知识库来源定位。

现在聊天回答下方的知识库来源卡片支持点击“定位片段”，打开文档 Markdown 预览弹窗，并高亮当前回答实际引用的 chunk。

## 实现内容

- 后端 `markdown-preview` 接口扩展返回 chunks：
  - `chunk_id`
  - `chunk_index`
  - `source_start`
  - `source_end`
  - `content`
- 前端知识库来源卡片新增“定位片段”按钮。
- 新增 `KnowledgeSourcePreviewDialog`：
  - 展示命中文档。
  - 展示 chunk index 和字符偏移。
  - 高亮命中片段。
  - 展示命中片段前后上下文。
- 前端定位策略：
  - 优先按 `chunk_id` 匹配。
  - 其次按 `chunk_index` 匹配。
  - 优先使用 `source_start/source_end`。
  - 如果 Markdown 预览中的内容因图片 URL 重写等原因导致偏移失效，则回退到 chunk 内容搜索。
  - 如果仍无法定位，则展示 chunk 原文，避免错误高亮。

## 当前边界

- 当前是局部上下文弹窗，不是完整文档滚动锚点。
- 暂未支持 PDF 页码、PDF 坐标、标题路径。
- 暂未持久化知识库检索日志。
- 旧历史消息如果没有完整知识库 metadata，不能定位。

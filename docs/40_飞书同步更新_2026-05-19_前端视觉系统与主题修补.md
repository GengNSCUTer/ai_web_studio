# 2026-05-19 前端视觉系统与主题修补同步

本次更新主要解决前端界面观感、深色模式对比度和未登录首页主题不一致问题。

## 本次完成

- 重做全局视觉方向：从早期暖绿/橙黄/重渐变风格，调整为中性灰背景、白色主面板、浅色侧边栏和蓝青主色。
- 新增语义化样式类：`app-shell`、`app-sidebar`、`conversation-card`、`message-card`、`tool-chip`、`context-chip`、`primary-action`、`settings-tab`、`auth-mode-button`、`theme-mode-button`。
- 统一主界面：左侧会话列表、会话菜单、聊天面板、消息气泡、输入区、Markdown 代码块都改为新的视觉系统。
- 修复深色模式设置面板左侧 tab 白底白字问题。
- 修复弹窗主按钮在深色模式下高亮不可读问题，覆盖重命名、分享、工作区保存、导出、长期记忆、Prompt 模板、设置保存等主操作。
- 首页登录 / 注册切换按钮改成清晰的分段控件，选中项使用蓝青主色。
- 首页文案更新为当前项目定位：`面向个人知识库的智能问答工作台`。
- 未登录首页接入主题机制：默认跟随系统，并提供 `跟随系统 / 浅色 / 深色` 切换。

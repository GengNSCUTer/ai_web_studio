# 2026-05-13 飞书同步更新：上下文治理第一阶段收尾

本次更新对应 AI Web Studio 上下文治理专项的 3 个收口项落地：

1. 附件片段可视化预览与点击展开
2. tokenizer 级预算与摘要质量观测
3. prompt prefix hash 与缓存命中观测

## 1. 本次已落地实现

- 后端新增 `TokenizerEstimator`，基于 `tiktoken` 返回 Prompt、摘要、附件、稳定前缀等 Token 估算
- 上下文诊断面板新增：
  - 本轮估算 Token 数
  - 附件片段 Token 数
  - 摘要 Token 数
  - 摘要源 Token 数
  - 摘要压缩比
  - 稳定前缀 Hash
  - 稳定前缀 Token 数
  - Prompt 总 Token 数
  - 最近历史 Token 数
  - 是否复用上一轮稳定前缀
- 后端新增 `x-context-details` 响应头，用于传输已选附件片段预览数据
- 前端“上下文治理诊断”弹层已支持查看已选附件片段，并可点击展开更长片段
- 会话表新增稳定前缀观测字段：
  - `last_prompt_prefix_hash`
  - `last_prompt_prefix_token_count`

# 飞书同步更新：P0 体验修补与 Project / 工作区雏形

更新时间：2026-05-17

## 本次完成

### 1. P0 体验修补

- 前端上传前校验文件类型和大小：
  - 图片：`png / jpg / jpeg / webp / gif`，单文件不超过 `10MB`
  - 文档：`txt / md / markdown / pdf / docx`，单文件不超过 `20MB`
- 后端多文件上传失败时会清理本轮已写入文件，避免部分文件成功落盘但请求整体失败后留下孤儿文件
- 窄屏 / 移动端下左侧侧边栏增加最大高度，避免侧边栏挤占整个屏幕

### 2. Project / 工作区雏形

新增后端数据模型：

- `projects`
- `conversations.project_id`
- `prompt_templates.project_id`

新增后端接口：

- `GET /api/projects`
- `POST /api/projects`
- `PATCH /api/projects/{project_id}`
- `DELETE /api/projects/{project_id}`

前端新增能力：

- 左侧栏新增工作区选择器
- 支持新建、重命名、删除工作区
- 工作区新建 / 设置使用项目内自定义弹窗，不再使用浏览器原生 prompt
- 工作区侧栏区域已收敛为一个“管理”入口，避免重命名、设置、删除三个按钮挤占左栏空间
- 支持按工作区筛选会话
- 当前工作区下新建会话会自动归属该工作区
- 工作区可配置默认模型和 System Prompt，其中默认模型通过模型列表下拉选择，System Prompt 使用 textarea 编辑
- 会话菜单支持移动到工作区或移出工作区；移动时可从弹窗下拉选择目标工作区
- Prompt 模板可选择全局模板或归属某个工作区
- Prompt 模板逻辑已重新收敛：
  - 所属工作区只表示模板可见范围
  - 模板卡片里的“应用目标”才表示真正写入位置
  - 可直接写入全局 System Prompt 或任意指定工作区 System Prompt

### 3. 聊天页细节修补

- 移除底部输入区上方的接通状态标签，减少无效信息占位
- 深色模式输入框改为半透明 composer token，并通过 `chat-composer` 例外类避免全局 dark textarea 背景造成突兀矩形底色
- 左侧工作区入口压缩为轻量选择器和小型操作按钮，减少对历史会话列表空间的挤占

## 验证结果

- 后端编译检查通过：`python -m compileall backend/app`
- 前端 lint 通过：`npm run lint`
- 前端生产构建通过：`npm run build`

## 后续建议

# 2026-05-17 更新：导出入口与深色模式修补

## 本次修补内容

本轮主要修补 P1 功能中的几个交互问题：

1. 会话菜单导出入口合并
   - 左侧会话菜单不再同时展示“导出选项 / 导出 Markdown / 导出 JSON”三个入口。
   - 现在只保留一个“导出选项”，所有导出配置都在弹窗中完成。

2. 附件导出语义拆分
   - `包含附件元数据`：控制 Markdown / JSON / ZIP manifest 中是否包含附件名称、类型、大小等元数据。
   - `ZIP 中包含附件文件`：只在选择“导出为 ZIP”时生效，控制是否把真实附件文件写入 ZIP。
   - 这样避免了“勾选了 ZIP 附件文件，但实际只下载 md/json 文件”的歧义。

3. ZIP 附件文件名修正
   - ZIP 中附件优先保留用户上传时的原始文件名。
   - 如果多个附件同名，则自动追加 `_2`、`_3` 等后缀。
   - 不再默认使用 `附件ID_原文件名` 作为导出文件名。

4. 深色模式按钮对比度修复
   - 收敛深色模式下的全局按钮文字覆盖规则，避免按钮自身设置的文字颜色被强制改写。
   - 修复长期记忆面板中“新增记忆”和建议记忆“保存”按钮在深色模式下低对比、看不清的问题。
   - 登录页的登录 / 注册切换按钮也同步使用主题变量，避免深色主题下白底浅字。

## 后端变化

- `GET /api/conversations/{conversation_id}/export` 新增参数：
  - `include_attachment_files`
- 现有参数语义：
  - `include_attachments`：是否导出附件元数据。
  - `include_attachment_files`：是否在 ZIP 中包含真实附件文件。
  - `include_context`：是否包含上下文摘要。
  - `as_zip`：是否导出 ZIP 包。

## 前端变化

- 会话菜单只保留“导出选项”。
- 导出弹窗新增独立的“ZIP 中包含附件文件”选项。
- 非 ZIP 导出时，该选项置灰，降低误解。
- 深色模式不再对所有按钮统一强制覆盖文字颜色，按钮颜色由组件语义样式控制。

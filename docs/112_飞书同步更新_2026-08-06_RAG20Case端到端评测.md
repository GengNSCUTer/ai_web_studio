## 端到端答案评测

端到端链路采用 Hybrid + Rerank（候选 top-20，Rerank 后 top-6），答案模型为 `deepseek-ai/DeepSeek-V4-Flash`，独立 Judge 为 `Qwen/Qwen2.5-72B-Instruct`。答案模型被要求返回带 `[KBn]` 引用的 JSON，系统先做确定性引用审计，再调用独立 Judge，避免把“引用标签格式正确”误当成答案事实正确。

| 指标 | 结果 | 口径 |
| --- | ---: | --- |
| Answer Faithfulness | 91.50% | Judge 判断答案事实是否被给定证据支持 |
| Answer Relevancy | 91.50% | Judge 判断答案是否直接回答问题 |
| Citation Correctness | 85.75% | Judge 判断引用是否支持对应结论 |
| Citation Validity | 100.00% | 确定性检查引用标签是否映射到本次返回来源 |
| Ground-Truth Citation Precision | 40.33% | 被引用来源中属于人工目标 Chunk 的比例 |
| Ground-Truth Citation Recall | 46.67% | 人工目标 Chunk 被引用覆盖的比例 |
| 已完成 Judge 的 Case | 20/20 | 检索、生成、Judge 均无失败 |
| 平均端到端耗时 | 14,477.5 ms | 检索 1,398.5 ms + 生成 3,581.8 ms + Judge 9,496.7 ms |

上述三个答案质量指标是固定内部 Gold Set 上的 LLM-as-a-Judge 分数，不等同于人工标注的最终答案准确率；Citation Validity 和 Ground-Truth 引用 Precision/Recall 是确定性审计。后续仍需扩大多领域测试集，并增加人工答案标签或多 Judge 交叉验证。

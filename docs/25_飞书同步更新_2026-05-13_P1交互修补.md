# 2026-05-13 飞书同步更新：P1 交互修补

本次在 `P1` 首批功能基础上，继续做了一轮交互与稳定性修补，重点是把一些“能用但不够像主流产品”的地方补齐。

## 1. 已完成内容

### 1.1 编辑上一条用户消息并重新回答

- 已从浏览器 `prompt` 弹窗改为消息内联编辑面板
- 编辑态支持：
  - 修改文本内容
  - 删除原有附件
  - 新增附件
  - 点击附件直接预览
- 提交后会直接复用现有流式回答链路重新生成最后一条回答

### 1.2 输入区待发送附件预览

- 输入区上传附件后，附件卡片已支持点击预览
- 图片、PDF、文档文本预览逻辑与历史消息附件预览保持统一

### 1.3 切换会话时的流式稳定性修复

- 后端对 `streaming` 助手消息改为“超时后才标记失败”，不再在会话加载时无条件判失败
- 前端在切回会话时，如果服务端仍返回 `streaming` 状态，会显示等待态提示，而不是空白回答框

## 2. 代码层变化

### 前端

- `chat-thread` 增加消息内联编辑态
- 待发送附件卡片支持点击预览
- 编辑态附件支持增删改
- 服务端残留 `streaming` 消息支持等待态展示

### 后端

- `edit-last-user-stream` 接口支持附件替换
- 附件仓储新增按消息删除能力
- 消息服务新增“替换用户消息附件”能力
- `streaming` 消息 stale 判定改为超时策略

## 3. 当前结论

这一轮完成后，`P1` 里“会话搜索 / 重生成 / 编辑重答 / 附件预览 / 归档置顶”这条产品补完链路已经更接近主流 AI 网页端体验。

后续更适合继续推进的方向：

- 深浅主题
- 会话导出 / 分享
- 更完整的消息级来源定位
- 更强的上下文治理和缓存优化

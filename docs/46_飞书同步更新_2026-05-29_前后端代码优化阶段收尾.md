# 2026-05-29 前后端代码优化阶段收尾

本次更新用于收尾当前这一小轮“前后端代码优化”，并明确项目主线从纯架构治理切回知识库实现。

## 一、本轮完成内容

### 1. 前端最后一轮结构收缩

- 新增 `frontend/src/components/chat-message-list.tsx`
- 将 `chat-thread.tsx` 中体量最大的消息渲染区抽离为：
  - `ChatMessageList`
  - `MessageItem`
  - `MessageActions`

当前前端职责边界：

- `ChatThread`：保留流式请求状态机、编辑状态、上传状态、聊天 handler 编排
- `ChatMessageList`：负责消息列表映射、空态、加载态、首 token 等待态
- `MessageItem / MessageActions`：负责单条消息渲染、附件展示、复制/重答/编辑等局部交互

这样做的结果是：

- 聊天主状态机不再和大段 JSX 消息 UI 混在一起
- 后续知识库引用、消息级来源跳转、RAG 片段卡片可以优先在消息层扩展
- 不需要继续为了“拆而拆”再细碎化组件

### 2. 后端聊天主链路测试补齐

- `backend/tests/test_chat_execution_service.py` 已扩展到 5 条关键路径：
  1. 新会话执行上下文构建
  2. 已有会话开启外部工具时的 Tool Trace 持久化
  3. 图片进入 Ollama 多模态上下文
  4. 最后一条回答重生成
  5. 编辑上一条用户消息并重答

测试策略：

- 使用 SQLite 内存数据库
- 使用 fake external context
- 路由级测试直接调用 async route，并 patch streaming builder

这样可以避免真实 PostgreSQL、真实 Ollama、真实外部 API 和完整 StreamingResponse 消费导致的脆弱测试。

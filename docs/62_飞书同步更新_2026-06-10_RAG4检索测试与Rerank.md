# 2026-06-10 更新：RAG-4 检索测试与 Rerank

AI Web Studio 知识库模块已完成 `RAG-4：检索测试增强与 Rerank` 第一版。

## 当前检索方式

当前知识库检索不是完整 Dify 式多模式检索，而是一个稳定可调试的两阶段检索：

```text
query
-> embedding
-> FAISS vector search
-> candidate chunks
-> optional rerank
-> score threshold
-> retrieval-test response
```

也就是说：

- 第一阶段是向量检索：query embedding 后走 FAISS 召回相似 chunk。
- 第二阶段是可选 Rerank：如果知识库启用 Rerank，则对候选 chunk 重排。
- 如果 Rerank 服务失败，会自动回退到向量召回，不让检索测试整体失败。

## 本轮完成

- 新增 `KnowledgeRerankService`：
  - `siliconflow / openai-compatible` 走 `/rerank`。
  - 使用用户级 `knowledge_rerank_api_key`。
  - Base URL 优先使用 `knowledge_rerank_base_url`，未配置时回退 `knowledge_embedding_base_url`。
- `KnowledgeIndexService.retrieve()` 已支持：
  - 向量召回。
  - 启用 Rerank 时二阶段重排。
  - Rerank 失败时自动回退向量召回。
  - 按最终分数执行 `score_threshold` 过滤。
- 检索测试 API 已返回更多可观测字段：
  - `vector_score`
  - `rerank_score`
  - `rank_source`
  - `rerank_enabled`
  - `rerank_model`
  - `metadata.rerank_error`
- 前端知识库详情页的检索测试面板已增强：
  - 展示当前是否启用 Rerank。
  - 展示 Rerank 模型。
  - 每条结果展示最终分数、向量分数、Rerank 分数。
  - 展示排序来源：向量召回 / Rerank / 向量回退。
  - Rerank 失败时展示回退原因。
- 补充后端单测：
  - 向量检索基础用例。
  - Rerank 成功重排用例。
  - Rerank 失败回退向量召回用例。

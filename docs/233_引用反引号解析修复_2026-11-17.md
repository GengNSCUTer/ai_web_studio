# 引用反引号解析修复

2026-11-17。修复P0-A验收中的K39误报，原200题189完整/9部分/2失败的报告不改分。

原`without_markdown_code()`使用跨全文正则匹配反引号，既可能将双反引号的一部分当作闭合，也会跨越空行，将后续正文和真实引用误排除。现在围栏代码仍过滤，行内代码按段落和完整等长反引号串匹配；未闭合符号不吞掉后续段落，同段内正常多行代码仍忽略其中的标签。开头转义的反引号保持普通文字。

实现：`backend/app/services/citation_audit_service.py`中`without_markdown_code()`与局部`_without_inline_code()`；测试位于`backend/tests/test_citation_audit.py`，覆盖不等长串、转义、多行、空白段落和围栏边界。它仍是第一层标签审计，不检查语义支持性，也不是完整Markdown渲染器。

60项引用/证据/任务评测/逐份文件相关测试通过，compileall与diff检查通过。K39原答案不变回放识别`[KB2]、[KB5]、[KB1]、[KB4]`，原needs_review变为passed，原来源范围和Gold检查均通过。此结果是修复后的原答案回放，不是新200题成绩或线上模型任务成功率。

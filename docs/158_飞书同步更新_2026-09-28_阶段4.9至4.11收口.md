## 阶段 4.11：审计导出与安全回放

1. `tool_execution_snapshot()` 对 ToolDefinition 的 provider、category、adapter 类型、输入输出 schema、质量合同、evidence profile、风险/只读属性生成稳定指纹；不把认证信息和完整固定参数写入快照。
2. Durable Run 入队保存工具快照；Worker 和人工 replay 前重新解析当前 Tool/Skill，比较 Tool fingerprint、Skill version 和 manifest digest。工具合同漂移、风险升级、Skill 停用或审核版本变化时失败关闭。
3. 新增用户作用域 `GET /api/agent-runtime/tool-runs/{run_id}/audit.jsonl`。JSONL 记录 Run、Step、Checkpoint、Artifact、Outbox 的状态、哈希、计数、版本摘要和错误码，不导出原始 arguments、完整 `content_json`、Provider 正文或凭据；旧 Run 明确标记 `legacy_snapshot`。
4. `/tasks` 任务详情新增“导出审计 JSONL”按钮，浏览器通过下载流获取当前 Run 记录；仍按用户权限隔离。

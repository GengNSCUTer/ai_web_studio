# 2026-06-07 RAG-2 文档解析与 MinerU 凭据同步更新

本次完成 `RAG-2：文档解析与 MinerU 凭据` 第一版。

## 已完成

- 用户级 MinerU token 加密保存、掩码展示和凭据来源提示。
- `local_basic` 本地基础解析：复用现有文件解析能力，把上传文件解析为 Markdown 并保存到用户隔离目录。
- `mineru` 远程解析：接入 MinerU 精准 API，流程包括申请上传 URL、上传文件、轮询 batch 结果、下载 zip、提取 `full.md`。
- 文档解析 API：`POST /api/knowledge-bases/{knowledge_base_id}/documents/{document_id}/parse`。
- Markdown 预览 API：`GET /api/knowledge-bases/{knowledge_base_id}/documents/{document_id}/markdown-preview`。
- 知识库详情页新增 MinerU token 配置、测试、文档解析、重新解析和 Markdown 预览。
- 任务列表支持展示执行中、成功、失败和错误原因。

## 安全边界

- 不在代码、文档、Git 或前端页面写入真实 MinerU token。
- 前端不回显 token 明文。
- 后端读取用户级加密凭据，只有未配置用户凭据时才使用 `MINERU_API_TOKEN` 环境变量作为开发兜底。
- 原始文件路径和 Markdown 路径均校验必须属于当前用户目录，避免越权读取。

## 当前边界

- MinerU “测试连接”当前不创建远程解析任务，只验证凭据存在和基础格式；真实远程连通性由解析动作验证。
- 当前解析任务仍由页面同步触发，后续大文件和批量入库应迁移为后台 worker。
- 当前只生成 Markdown，不生成 chunks、不调用 embedding、不写 FAISS。
- 聊天页暂未接入知识库选择器，RAG 引用进入后续 `RAG-5`。

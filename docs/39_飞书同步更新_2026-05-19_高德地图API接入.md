# 2026-05-19 高德地图 API 接入更新

本次把地图类问题从 Tavily 回退改为真正进入高德地图 Web 服务 API。

## 已完成

- `RuleBasedToolRouter` 中地图类问题改为路由到 `map`。
- 新增高德地理编码：用于地址、地点定位。
- 新增高德 POI 文本搜索：用于“某地点在哪里 / 地址 / 位置”类问题。
- 新增高德 POI 周边搜索：用于“某地附近咖啡店 / 酒店 / 餐厅”等问题。
- 新增高德路径规划：支持驾车、步行、公交/地铁方向的第一版路线摘要。
- 新增高德行政区域查询：用于“广州行政区有哪些”等问题。
- 地图结果统一输出为 `ExternalSource(source_type="map", provider="amap")`，复用现有来源卡片和 Prompt 注入链路。

## 已验证示例

- `华南理工大学在哪里`：返回高德 POI 搜索结果。
- `从华南理工大学到广州南站怎么走`：返回高德驾车路线。
- `从华南理工大学到广州南站坐地铁怎么走`：返回高德公交/地铁路线。
- `广州行政区有哪些`：返回高德行政区域结果。
- `广州南站附近咖啡店`：返回高德周边 POI 结果。

## 当前边界

- 当前仍是规则级 Query 抽取，不是 LLM Tool Router。
- 地图结果展示仍复用通用来源卡片，后续可以做专门的地图卡片。
- 多工具组合问题仍未做并行工具执行。
- 高德 MCP 暂未接入，当前直接使用 REST API。

## 下一步建议

1. 增加工具调用过程事件和 Trace 持久化。
2. 为地图来源增加更清晰的前端卡片，例如距离、耗时、地址、路线步骤单独展示。
3. 把 `ExternalContextService` 拆分成 Tool Registry、Tool Router、Tool Executor 和 Provider。
4. 后续再考虑高德 MCP 或 LLM Tool Router。

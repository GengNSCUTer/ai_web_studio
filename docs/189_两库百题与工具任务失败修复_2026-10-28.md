# 两库各百道中文题与工具任务失败修复

两套各100道中文题已完成原文绑定、独立审核和入库；完整题本见[190题目与答案依据](190_中英文两库各100题_题型与答案依据_2026-10-28.md)，检索与答案验收见[191报告](191_两库百题RAG验收_2026-10-28.md)。历史90/16题及中间失败结果继续保留。新题集与旧题集不同，不能直接把新旧分数差称为性能升降。

## 题集设计

英文论文库与顺序修复后的中文后端资料库各100道中文问题，各含95道可回答题、5道无答案题。固定题型配额：事实定位20、机制解释20、多证据综合20、比较辨析12、步骤/应用10、数值/条件8、局限/纠错5、无答案5。

采用活动原文先出题、代码绑定实际文档/Chunk/引文、独立模型审核支持关系与类型，再整体去重。无答案题不绑定伪造正例；综合题至少两个不同块，不能同一块引用两次凑数。出题和修订阶段不读取任何检索得分。保留草稿拒绝原因、限流与截断记录；维护者与模型辅助标注，不是外部专家盲测，也不承诺已穷尽所有正确证据。

## Tool 的历史失败与当前复现

2026-10-27 的20题：8题满足旧完整断言。12个失败包括文件3、天气/组合6、搜索链接1、技术文档2。2026-10-28 同题、同断言、修复前重新执行仍为8/20；具体失败样本受生成波动影响，并不是每次都恰好相同题失败。

来源：`backend/evals/results/tool_tasks_20261027.json`、`tool_tasks_20261028_before.json`。后者保留规划与参数等诊断事件。不能用工具调用HTTP成功率100%或候选Recall98.33%替代任务完成率。

已定位：

- 文件搜索是词法检索，中文关键词无法匹配纯英文正文；空搜索不等于文件不存在。原流程可能在list/search后停止，缺少正文核验；也存在工具返回正确片段但最终回答仍说未找到的样例。
- 高德MCP原工具只返回预报，任务却要求实时天气；如实告知预报仍不能算完成实时任务。
- Context7 resolve只是库候选，缺少query正文步骤；没有激活专门Skill时，完成要求原先覆盖不足。在线Planner超时的通用兜底也可能换成不合适的网页搜索。
- 模型只给来源编号、不交付用户明确要求的URL；原评测甚至可能接受第三方页面冒充所要求的官网来源，需要同时加强评测。
- 多轮Planner会重复使用call_1，旧持久化按call_id归并，后轮文件调用可能覆盖前轮天气记录。结果正文仍存在也不代表审计记录完整；这一问题是在重复运行而非首轮通过时发现的。

## 本轮修复代码

- `tools/completion_contract.py`、`external_context_service.py`：普通对话明确查文件/Context7文档时，同样需要正文证据，缺少时要求有限继续；只是完成检查，不授予工具权限。
- `tools/planner.py`：补充跨语言词法失败后的list/read策略；模型超时可用已核实ID做只读延续，不猜文件或库ID，不把指定文档提供方悄悄换成网页。
- `tools/adapters.py`、`providers/amap.py`、`default_tools.json`：天气新增live/forecast，实况访问固定官方REST接口，预报保留MCP；结构化city/adcode不再落入旧自然语言默认城市，平台mode不传给不接受该参数的MCP。仍走凭据/权限/Schema/质量检查，不开放任意HTTP。
- `tools/formatter.py`：已取得正文时不让同提供方库简介竞争预算；文件正文排在空搜索之前，但保留空搜索的检查范围，不能因读取另一文件而删掉真实缺失信息；明确要求交付真实来源URL。
- `external_context_service.py`：对跨轮重名调用分配运行内唯一ID，同步更新DAG依赖、结果绑定与事件，并保留映射审计；不修改工具业务参数里的同名字段。单计划内的重复ID仍交给原校验拒绝。
- `scripts/evaluate_tool_tasks.py`：旧评分保留可比；额外严格检查真实正文、实况城市/温度、实际引用URL和官网域名，旧答案不能按缺失数据强行追算严格分数。
- `backend/scripts/build_rag_100.py`、相关评测汇总脚本：固定槽位、真实引文编号绑定、独立审核及题型分组指标；旧结果不覆盖。

高德实况/预报参数依据[官方天气接口](https://lbs.amap.com/api/webservice/guide/api/weatherinfo)；标注脚本JSON模式依据[硅基流动JSON模式](https://docs.siliconflow.cn/docs/userguide/guides/json-mode)。容器沙箱仍未验收，继续禁用，本轮不借工具修复扩大高风险权限。

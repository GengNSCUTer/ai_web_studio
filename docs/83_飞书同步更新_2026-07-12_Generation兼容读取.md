# 2026-07-12 RAG Index Generation：Legacy 兼容读取基础

## 设计目标

为数据库 chunks、FAISS、BM25 建立共同的索引版本标识，并在不搬迁现有文件、不重算现有索引的前提下兼容当前数据。

## 本轮完成

- 新增 `KnowledgeBase.active_index_generation`，当前/历史默认值为 `legacy`。
- 新增 `KnowledgeChunk.index_generation`。
- 新增 `KnowledgeIndexGeneration` 状态记录模型，为后续 building/ready/failed/obsolete 和 CAS 激活做准备。
- 增加 `(knowledge_base_id, index_generation, vector_id)` 唯一约束；不同代可以重用 vector ID，同代不能重复。
- FAISS/BM25 Store 支持两种路径：legacy 继续使用旧目录，新 generation 使用 `generations/<generation_id>/`。
- RetrievalPipeline 将 active generation 同时传给文件 Store 和数据库 Repository，避免新文件命中映射到旧代 Chunk。
- KnowledgeContext、retrieval-test、lexical fallback 和 in-memory BM25 路径均按 active generation 过滤。

# 2026-06-09 更新：知识库模型候选移除 builtin 来源

本次根据设置页测试反馈，调整知识库 Embedding/Rerank 模型候选来源策略。

## 1. 调整原因

之前模型列表来源可能显示为 `remote+builtin`，表示远程 provider 返回的模型列表与项目内置候选列表合并展示。

这个策略虽然可以防止远程接口不可用时下拉框为空，但会带来两个问题：

- 用户看到的模型不一定是真实 provider 当前返回的模型。
- `remote+builtin` 概念容易误导用户，不清楚哪些模型真实可用。

因此本次去掉 builtin 合并逻辑，模型候选以远程 provider 返回为准。

## 2. 当前行为

`KnowledgeModelCatalogService` 当前策略：

- `siliconflow / openai-compatible`：调用 OpenAI-compatible `/models`。
- `ollama`：调用本地 Ollama 模型列表。
- 如果远程列表中能通过关键词识别 Embedding/Rerank，则展示过滤后的列表。
- 如果关键词过滤结果为空，则展示远程全量列表，避免误删 provider 返回的可用模型。
- 如果远程接口失败：
  - 手动“测试连接”使用 `strict=true`，直接显示连接失败。
  - 自动静默刷新使用 `strict=false`，不报错，但返回空候选和 `remote-unavailable` 来源。

## 3. 已修改内容

- 移除 `KnowledgeModelCatalogService` 内置 SiliconFlow Embedding/Rerank 候选表。
- 移除 `remote+builtin` source。
- 前端初始来源从 `builtin` 调整为 `remote`。
- 本地文档中同步移除“回退内置候选”的说明。
- 新增单测，确认远程列表不会混入 `BAAI/bge-m3` 这类旧内置候选。

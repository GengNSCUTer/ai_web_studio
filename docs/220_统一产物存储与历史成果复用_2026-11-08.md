## 用户现在可以怎样使用

文档任务完成后，用户新建同项目会话，要求“查找以前生成的文档草稿，读取后总结用途与安全边界”。模型可调用`agent.artifacts.list`，按问题、类型、时间范围得到真实ID，再调用`agent.artifacts.read`读正文；不需要用户提供旧Run/Step/Artifact ID，也不需要重新生成原文档。

默认只本地术语匹配和近期排序。`semantic=true`是可选在线Embedding精排，最多24条、每条1000字符脱敏预览与300字符问题、4秒超时；只有原问题明确允许在线语义/Embedding查找才可使用。用户禁止联网或模型擅自打开时，Executor拒绝。异常回退到本地检索，不启动Ollama，不外发完整产物或凭据。候选最多扫描60条、返回20条；不是无限量历史全文搜索，也不是为全部历史成果预建ANN索引。

## 同一个存储入口

`agent_artifact_store.py`负责创建、大小/JSON/内容哈希、用户/Run/Step关联、可见性和复用检查。`ToolInvocationRuntime.create_artifact`调用它，Chat逐工具结果和中断片段、Durable结果、Document的证据/草稿/导出/交付全部经此入口。生产服务中只剩该文件构造AgentArtifact，没有新增五张表。

| 既有物理类型 | 逻辑类型 | 可被产物工具发现 |
| --- | --- | --- |
| tool_result | tool_result | 当前权限与时效复核后允许 |
| document_evidence | evidence_snapshot | 来源复核后允许 |
| document_draft | document_draft | 来源复核后允许 |
| document_export | exported_file | 工具只读正文/来源，不读取base64；下载仍原接口 |
| document_delivery | delivery_receipt | 来源复核后允许 |
| chat_tool_result | tool_result | 隐藏，内部类型恢复数据 |
| chat_generation_partial | generation_partial | 隐藏，内部中断档案 |

物理格式保留以读取旧记录，工具展示增加format_version=1、逻辑类型与snapshot_at；文件版本仍由原FileRevision负责。数据随Run删除级联清理，当前不后台自动删除用户报告。自动复用默认查7天内、可显式放宽到30天；天气/路线/距离快照不超过15分钟。撤销/过期/归档状态不会自动进入模型证据。保留原记录不等于无限期当作当前事实。

## 来源和权限

读取当前用户/当前项目的已成功Step产物，再验证哈希。工具和安全快照变化、工作区禁用会阻止复用；文件来源校验归属及正文版本；知识库来源检查当前用户/项目与active generation；文档草稿/导出继承最初资料、原答案generation与内容快照。派生产物的上游被撤销/过期时阻断，引用链有深度和总检查数上限，拒绝循环。产物读取不授予执行原工具的权限，也不代表用户已批准保存到工作区。

# 2026-06-09 知识库模型设置增强

本次更新继续完善 RAG 阶段前置配置，重点解决两个问题：

## 1. 已完成

### MinerU 配置进入设置中心

设置中心“知识库模型”页签现在可以直接配置 MinerU token：

- 保存 MinerU token。
- 掩码展示已保存凭据。
- 测试 MinerU 凭据。
- token 继续按用户级加密保存，不回显明文。

### 知识库模型 API Key 独立化

新增知识库模型 API Key：

- 独立于聊天问答模型 API Key。
- 用于后续 Embedding/Rerank provider。
- 后端加密保存。
- 前端支持保存、清空、掩码展示。

这样后续可以支持：

- 聊天模型用本地 Ollama。
- 知识库 Embedding/Rerank 用 SiliconFlow 或其他 OpenAI-compatible 服务。
- 不同用户配置自己的知识库模型服务凭据。

### Embedding/Rerank 模型候选动态刷新

新增后端接口：

```text
POST /api/settings/knowledge-model-options
```

行为：

- `ollama`：读取本地 Ollama `/api/tags` 模型列表。
- `siliconflow / openai-compatible`：优先调用 OpenAI-compatible `/models`。
- 先按 provider 能力映射表识别已知 Embedding/Rerank 模型。
- 再用名称关键词过滤补充候选。
- 最后追加远程全量模型作为手动选择兜底。
- 合并内置常用候选。
- 服务不可用时回退到内置候选。
- 前端仍支持手动输入任意模型名。

当前内置候选已扩充：

- `BAAI/bge-m3`
- `Qwen/Qwen3-Embedding-0.6B`
- `Qwen/Qwen3-Embedding-4B`

- `Pro/BAAI/bge-large-zh-v1.5`
- `Pro/BAAI/bge-large-en-v1.5`
- `Pro/netease-youdao/bce-embedding-base_v1`

Rerank：

- `BAAI/bge-reranker-v2-m3`
- `Qwen/Qwen3-Reranker-0.6B`
- `Qwen/Qwen3-Reranker-8B`
- `Pro/BAAI/bge-reranker-v2-m3`
- `Pro/netease-youdao/bce-reranker-base_v1`

### 前端交互

- 进入“知识库模型”页签时自动静默刷新候选模型。
- 切换 Provider 或 Base URL 后自动刷新候选模型。
- 用户也可以手动点击“刷新模型列表”查看来源。
- 切换 Provider 时自动填默认 Base URL：
  - `ollama` -> `http://127.0.0.1:11435`
  - 其他 -> `https://api.siliconflow.cn/v1`
- 选择常见 Embedding 模型时自动推断维度，仍允许手动覆盖。

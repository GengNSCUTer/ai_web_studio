# 飞书同步更新：P1 主题、导出与 Prompt 模板

更新时间：2026-05-17

## 本次完成

本次补齐了三个偏产品化的 P1 能力：

1. 深色 / 浅色主题
   - 用户设置新增 `theme_mode`
   - 支持 `system / light / dark`
   - 前端通过 `data-theme` 和 CSS token 切换主界面、设置弹窗、输入控件等主要区域颜色
   - 主题选择会持久化到后端用户设置

2. 会话导出
   - 后端新增 `GET /api/conversations/{conversation_id}/export?format=markdown|json`
   - 支持导出 Markdown 与 JSON
   - 导出内容包含会话元数据、消息内容、消息状态、附件元信息
   - 前端左侧会话菜单新增“导出 Markdown / 导出 JSON”

3. Prompt 模板
   - 后端新增 `prompt_templates` 表
   - 新增模板 CRUD 接口：`GET / POST / PATCH / DELETE /api/prompt-templates`
   - 前端设置面板新增“Prompt 模板”分区
   - 支持模板新增、编辑、删除、设为默认
   - 支持一键应用模板到当前 System Prompt，并可带默认模型

## 技术变化

- `user_settings` 增加 `theme_mode` 字段，运行时 schema migration 会自动补列
- 新增 `PromptTemplate` 模型、repository、service、schema 和 router
- 会话导出沿用当前用户鉴权，只能导出自己的会话
- Next.js `/api/backend/[...path]` 代理补充转发 `content-disposition`，便于浏览器下载文件
- 前端设置面板从原有模型、生成、上下文、长期记忆、系统提示，扩展为包含“Prompt 模板”和“外观”

## 验证结果

- 后端编译检查通过：`python -m compileall backend/app`
- 前端 lint 通过：`npm run lint`
- 前端生产构建通过：`npm run build`

说明：第一次 `npm run build` 在沙箱内因 Turbopack 绑定本地端口被拦截，放宽权限后完整构建通过。

## 后续建议

下一步可以继续推进：

1. Project / 工作区雏形：按项目组织会话、文件、提示词和默认模型

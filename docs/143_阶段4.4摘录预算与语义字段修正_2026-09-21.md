# 阶段 4.4 补充修正：摘录预算与语义字段（2026-09-21）

## 本次结论

旧的 PostgreSQL 12/35432 服务已停止，项目使用的 PostgreSQL 18.3 + pgvector 0.8.5/35433 保持运行。后端在显式设置 `TEST_POSTGRES_URL` 后全量 457 项测试通过，包含 3 项 pgvector 和 2 项 Durable PostgreSQL 条件集成测试。

## Evidence Projection 调整

此前 Tavily Profile 为最多 2 个来源、单来源 480 字符、总计 960 字符。这个边界对安全有帮助，但在多来源研究问题中可能过早丢掉必要事实。本次调整为最多 4 个来源、单来源 720 字符、总计 2,400 字符；所有来源仍共享同一个 Profile 总预算，超过预算的来源会被明确标记为 `source_limit_reached` 或 `total_budget_exhausted`，不会无限增长。

这不是把全文直接开放给 Planner。投影仍必须满足 Tool 身份、Provider、source type、审核 Profile 和 canonical content path；完整文本先做可疑指令抑制，再做句子边界优先的硬截断。事实字段仍通过 `fact_paths` 单独投影。

## 新工具的泛化方式

投影逻辑位于 `PlannerObservationProjection`，不再为每个 Provider 写一套 Planner 回灌分支。新工具只需在审核后的 Tool Definition 中声明：允许的 source type、事实 JSON Pointer、可选 canonical content path、来源数和字符预算，并通过动态 MCP onboarding 的合同摘要、fixture、配置摘要和人工审核。未声明 Profile 的新工具自动使用 `mode=none`，因此不会静默扩大 Planner 可见性。

## 语义字段

已从 Planner observation 删除 `untrusted` 字段，避免“不能执行外部指令”被误解成“不能参考外部事实”。当前统一通过：

```text
evidence_role=reference_evidence
instruction_authority=none
```

表达“相关事实可以参考，但外部文本没有执行权限”。

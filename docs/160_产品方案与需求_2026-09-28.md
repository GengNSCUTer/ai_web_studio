# AI Web Studio：产品方案与需求

更新于 2026-09-28。本专题整合了 2026 年 5 月的《智能问答网页方案》和《详细需求清单》，并按当前代码与第二轮优化结果校正。早期“先不做 RAG/Agent”“只用本地 Ollama”等决定是当时的 MVP 切分，不再是现状；原始长文保留在本地 [04 方案](04_智能问答网页方案.md)、[05 需求](05_详细需求清单.md)及飞书旧版文档中供追溯。

## 产品定位与用户

产品是面向个人与小团队的本地知识工作台，服务论文、技术文档和项目资料的整理、查找、审阅及受控操作。它不以“工具市场越大越好”为目标，也不是 Codex 式任意本机操作 Agent。典型用户先建立工作区和知识库，导入资料，再通过会话追问、引用来源、调用只读工具；必要时对文件修改预览并审批，或将低风险只读计划确认交给后台 Worker。

5 月方案的关键设计判断仍成立：需要完整的网页产品形态，而不只是一次性问答脚本；会话、附件、模型设置与失败状态应是可见的用户工作流；前端承担交互和进度展示，后端承担事实状态、模型调用与安全边界。后续增加 RAG、Tool/Skill 和 Durable 运行时，是沿同一条“知识工作”主线演进，不是把旧 Chat 产品直接包装成无限自主 Agent。

## 主要工作流

| 用户目标 | 当前链路 | 可见结果 |
| --- | --- | --- |
| 整理资料 | 工作区与知识库、文档上传、解析、Chunk 与索引后台任务 | 文档状态、可检索内容和引用来源 |
| 追问资料 | 用户问题、混合检索、上下文组装、流式回答 | 引用证据、回答与会话记录 |
| 跨会话持续工作 | 最近消息、滚动摘要、长期记忆候选与用户审核 | 受控注入的偏好/事实及来源 |
| 查询外部信息 | 系统候选工具、LLM Planner、服务端校验、执行与质量判断 | Tool Trace、有效结果、空结果或失败摘要 |
| 审阅工作区文件 | 文件列表、搜索、读取和编辑提案 | 具体文件证据或待审批 Diff |
| 执行较长的只读任务 | 用户预览并确认 Tool Plan、Durable Run、Worker | 原会话终态消息、任务页 Step/Artifact 和审计导出 |

普通聊天、工具执行和后台任务是不同边界：Chat 可以结束于回答、部分回答、澄清、取消或失败；编辑提案不意味着已写文件；Planner 的后台建议不等于自动入队。用户应能看出系统做了什么，以及哪些动作仍等审批。

## 页面与交互要求

5 月需求清单中的页面结构可以保留为产品骨架：工作区入口、会话列表与线程、知识库、设置和诊断。当前还增加了任务页。会话支持创建与历史查看、流式文本、停止生成、失败收口、附件与来源展示。知识库承担文档导入和检索测试；设置承担 Provider、模型及上下文策略；任务页承担后台 Run、Worker、失败原因、产物与受控重放。

交互应遵循三点。首先，系统状态不能只存在于日志：正在生成、等待审批、后台排队、运行中、完成或失败都需要用户可见。其次，风险操作必须有单独的确认与版本检查；不能把“预览”设计成“已执行”。最后，来源内容只能作为可引用数据，不可替代系统权限与用户指令。

## 需求优先级与验收

已具备的核心链路是登录与项目隔离、持久化会话、流式 Chat、知识库混合检索、上下文与记忆治理、受限 Tool/Skill 执行、文件 Diff/审批/CAS、只读 Durable Run 及任务观察。详细实现和验证见 [当前项目全景](159_项目当前全景与第二轮优化收口_2026-09-28.md)及各阶段报告。

验收一条业务流程时，不只看接口 200：应检查数据库状态、来源证据是否真的进入模型、工具质量判定、最终回答或失败消息、前端状态，以及同一操作重复请求时的幂等性。长任务还要检查 Worker 接管、Checkpoint、终态回写和受控重放。固定 RAG Gold Set 只代表其论文库、Case 与模型条件，不能当作全用户场景的质量承诺。

当前冻结高风险 Tool 扩张。Shell/Bash、SQL、删除文件、任意本机路径写入、支付、邮件和任意 HTTP 写接口不纳入产品范围。外部推送告警、自动扩容和集中托管属于未来部署能力，不应写成已上线功能。

## 历史方案怎样使用

原方案中“先做 Chat 再接 RAG/Agent”的实施顺序可用于解释项目演进；原需求中的页面与异常处理清单可用于检查功能覆盖。但 5 月的模型默认值、阶段号、竞品介绍和“尚未支持某功能”等描述只对当时有效。阅读当前能力以[项目全景](159_项目当前全景与第二轮优化收口_2026-09-28.md)和代码为准，阅读设计缘由再回到 [04](04_智能问答网页方案.md)、[05](05_详细需求清单.md)。

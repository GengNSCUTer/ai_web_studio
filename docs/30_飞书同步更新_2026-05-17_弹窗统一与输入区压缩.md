# 飞书同步更新：弹窗统一与输入区压缩

## 本次修补

### 1. 原生浏览器弹窗替换

前端已清理 `window.prompt` 和 `window.confirm`，以下操作改为项目内统一弹窗：

- 会话重命名
- 删除会话
- 删除工作区
- 删除 Prompt 模板
- 批量删除消息

这样可以避免浏览器默认弹窗破坏整体视觉风格，也方便后续继续扩展二次确认、危险操作提示和移动端适配。

### 2. 输入区高度压缩

- 聊天输入框默认从两行视觉高度压缩为更紧凑的一行起步。
- 输入框仍保留自动增高能力，但最大高度降低，避免长输入过度挤占会话内容区域。
- 上传附件、上下文、停止生成和发送按钮调整到同一操作行。
- composer 内边距和按钮高度同步压缩，给中间消息列表留出更多显示空间。

## 验证

- `rg` 检查前端已无 `window.prompt` / `window.confirm`。
- `npm run lint` 通过。
- `npm run build` 通过。

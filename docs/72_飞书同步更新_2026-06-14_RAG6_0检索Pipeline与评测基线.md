# 2026-06-14 RAG-6.0 检索 Pipeline 与评测基线

本次完成 RAG-6.0 第一版开发，重点是先建立检索质量治理的架构边界和可重复评测基线，而不是直接开始 Hybrid Search。

## 已完成

- 新增 `KnowledgeRetrievalPipeline`，把 query-time retrieval 从 `KnowledgeIndexService` 中拆出。
- `KnowledgeIndexService` 继续负责文档索引构建，保留 retrieve 兼容入口。
- `KnowledgeContextService` 和知识库检索测试默认走 `KnowledgeRetrievalPipeline`。
- 新增评测相关数据模型：
  - `knowledge_eval_sets`
  - `knowledge_eval_cases`
  - `knowledge_eval_runs`
  - `knowledge_eval_results`
- 新增 `KnowledgeEvaluationService`，用于运行检索评测并计算基础指标。
- 新增评测 API：
  - 创建 / 列出评测集。
  - 创建 / 列出评测用例。
  - 运行检索评测。
  - 列出评测运行记录。
- 前端知识库详情页新增 `RAG-6.0 检索观测` 面板：
  - 刷新最近检索日志。
  - 创建小型评测集。
  - 添加评测用例。
  - 运行评测。
  - 展示 `Hit@K`、`MRR`、`Precision`、`Recall`。
- 检索测试结果展示 `chunk_id`，便于手动创建 expected chunk 用例。

## 当前指标

第一版评测指标：

- `hit_at_k`
- `mrr`
- `context_precision`
- `context_recall`

当前指标只衡量检索质量，不衡量最终答案质量。

## 当前边界

- 检索日志详情仍是摘要面板，不是完整单日志详情页。
- 评测用例需要手动填写 expected chunk id。
- 尚未支持从检索结果一键加入评测集。
- 尚未实现 Hybrid / BM25 / RRF。

## 下一步

1. `RAG-6.1`：metadata schema + metadata filter。
2. 增强 RAG-6.0 易用性：从检索结果一键加入评测集、查看单次评测结果详情。
3. `RAG-6.2`：多知识库检索。
4. `RAG-6.3` / `RAG-6.4`：BM25、Hybrid Search、RRF。

## RAG 测量方法

使用现有 `KnowledgeEvaluationService` 跑 Vector、BM25、Hybrid、Vector+Rerank、Hybrid+Rerank 五组；候选 top-k=20，启用重排时最终最多返回 6 个文本块。应同时列出实际返回规模及统一 @6 的比较，不能把“候选取20、最终返回6”的结果直接称为重排前 Hit@20。

检索指标：Hit、MRR、nDCG、Context Precision、Context Recall、文档命中、检索耗时和降级/失败数。Chunk 相关性按预先指定的精确块 ID 判断，未标注的同义或其他正确块可能被当作不相关，因此应同时查看答案证据与失败案例。

答案模型为 `deepseek-ai/DeepSeek-V3.2`，独立 Judge 为 `Qwen/Qwen2.5-72B-Instruct`。答案生成时固定使用 Hybrid+Rerank 和证据上下文，再评估 Faithfulness、Answer Relevancy、Citation Correctness，并确定性核对引用有效性及目标证据引用 Precision/Recall。三个并发评测线程，每题独立 Session；逐题保存，失败不删除，报告同时保留完成数量和全题分母。

这条答案评测覆盖检索、证据组装、模型回答和引用评审，不等于浏览器全部 Chat 模式、记忆和工具执行的综合成功率。网络等待期间与其他评测并行，耗时是该开发机上的本次观测值，不宣称线上 SLO。

## 已发现的实际缺口

中文问题查询只有英文关键词的文件时可能返回合法空结果，Planner 不一定继续按文件名查找或读取。天气工具当前返回预报，不能完成实时天气请求，回答有说明预报限制但任务仍未完成。技术文档查询存在参数或后续规划不足，搜索答案有时只给来源标签而没有满足题目要求的 URL。已记录调用成功率为 100% 与任务成功率只有 40% 可以同时成立，不能只选高数字宣传。

浏览器已验证新增论文可见、26 篇均有解析/索引状态且无 console/page error。页面还存在旧的 FAISS/RAG 阶段文案，与当前 pgvector 和引用能力不一致，此次记录为后续文案清理项，不将无控制台错误表述为界面语义完全正确。

## 文件职责与验证

- `backend/scripts/expand_paper_eval.py`：按活动文档生成来源优先题目，记录原文、独立审查和检索前剔除。
- `backend/scripts/import_rag_gold_set.py`：核对文档名、块编号与原文片段，绑定真实 ID 并持久化题集。
- `backend/scripts/run_rag_eval_matrix.py`：复用现有服务运行五组检索并保存数据库结果。
- `backend/scripts/run_rag_expanded_e2e.py`：并发真实模型生成、独立 Judge、引用审计和逐题结果保存。
- `backend/scripts/summarize_expanded_eval.py`：从数据库原始结果统一重算前6条，输出五组对比、旧/新题分组和逐题指标，不重新检索。
- `scripts/evaluate_tool_candidates.py`：规则/语义候选层对比。
- `scripts/evaluate_tool_tasks.py`：真实 Chat 到工具与最终回答的业务断言，以及独立安全拒绝测试。
- `backend/tests/test_tool_evaluation_metrics.py`：验证分层指标、组合任务和空分母，防止“请求成功”冒充“任务完成”。

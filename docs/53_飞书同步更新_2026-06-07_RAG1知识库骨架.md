# 2026-06-07 RAG-1 知识库骨架落地

## 本次阶段

AI Web Studio 已从工具调用阶段正式进入知识库 / RAG 主线。本次完成 `RAG-1：知识库模型与页面骨架`，目标是先把知识库作为独立产品模块立起来，暂不进入 MinerU 解析、chunk、embedding、FAISS 和聊天引用。

## 已完成

- 新增后端知识库数据模型：
  - `KnowledgeBase`
  - `KnowledgeDocument`
  - `KnowledgeJob`
- 新增后端知识库 API：
  - 知识库列表、创建、详情、更新、删除
  - 文档列表、创建记录、删除记录
  - 任务列表
- 新增后端知识库服务层：
  - 创建知识库时保存 parser、chunk、embedding、rerank、retrieval 配置
  - 文档记录绑定现有上传链路返回的 `storage_key`
  - 上传文档后创建 `parse_document` 的 `pending` job
  - 校验知识库、文档和工作区归属，保证用户隔离
- 新增前端知识库页面：
  - `/knowledge`
  - `/knowledge/[id]`
  - 知识库列表、新建知识库、配置概览、文档列表、任务列表、文档上传入口
- 更新项目协作规范：
  - `AGENTS.md` 已补充“每次修改完必须按改动范围执行测试/检查，并在回复中说明验证结果”的要求

## 当前边界

- 文档上传后只创建文档记录和 pending job。
- 当前不会执行 MinerU 解析。
- 当前不会生成 chunk。
- 当前不会调用 embedding / rerank。
- 当前不会写 FAISS index。
- 当前聊天页还没有知识库选择器和 RAG 引用。

# 飞书同步更新：P1 主题与导出修复

更新时间：2026-05-17

## 修复内容

本次针对 P1 第三批功能做了两个稳定性修复：

1. 深色模式可读性修复
   - 补充深色模式下 `hover:bg-white` 等 Tailwind hover utility 的覆盖规则
   - 补充原生 `select option` 在深色模式下的背景色、文字色和选中态样式
   - 目标是避免设置页里鼠标移动到某个选项或按钮行时出现白底浅字、内容看不清的问题
   - 上下文诊断面板已改为 token 化样式，统计数字卡片、附件片段、上下文提示和高级诊断区域不再使用浅色硬编码背景
   - 新增旧浅色 surface 兼容层，统一兜底 `bg-white/xx`、浅米色背景、浅色边框和危险提示色，避免后续继续逐个组件修补

2. 会话导出失败修复
   - 导出 Markdown / JSON 报错的主要原因是中文会话标题直接写入 `Content-Disposition` 的 `filename`
   - HTTP header 对非 ASCII 字符不安全，可能触发服务端编码异常
   - 当前改为：
     - `filename="conversation.md/json"` 作为 ASCII fallback
     - `filename*=UTF-8''...` 保存 UTF-8 编码后的真实文件名
   - 这样既避免后端 500，也尽量保留中文文件名兼容性

3. 历史会话滚动修复
   - 左侧历史会话列表原先使用固定 `max-height` 估算可滚动区域
   - 当上方用户信息、provider 信息、浏览器缩放或窗口高度变化时，底部会话可能被截断
   - 当前改为标准 flex 滚动布局：外层 `min-h-0 flex-1 flex-col`，列表区域 `min-h-0 flex-1 overflow-y-auto`
   - 修复会话较多时鼠标滚轮无法滚到更早会话的问题

## 验证结果

- 后端编译检查通过：`python -m compileall backend/app`
- 前端 lint 通过：`npm run lint`
- 前端生产构建通过：`npm run build`

## 后续注意

- 原生浏览器下拉框的 hover 样式在不同浏览器和操作系统上可控性有限。如果后续仍觉得体验不够好，可以把设置页的 select 改为自定义下拉组件。
- 会话导出当前只导出消息正文和附件元信息，后续如果要导出附件原文件，需要新增压缩包导出或异步导出任务。

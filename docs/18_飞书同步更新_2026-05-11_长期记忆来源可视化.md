# 2026-05-11 更新：长期记忆来源可视化

## 本次完成

- 长期记忆列表新增来源会话展示。
- 后端返回长期记忆时补充来源会话标题。
- 前端长期记忆卡片支持点击“打开来源”，跳转到对应历史会话。
- 本地文档补充了当前上下文治理与长期记忆的实现边界。

## 后端变化

- `UserMemoryResponse` 新增 `source_conversation_title`。
- `MemoryService` 在返回记忆时根据 `source_conversation_id` 查询用户自己的会话标题。
- 记忆列表、新增、更新接口均返回来源会话标题。

## 前端变化

- `UserMemory` 类型新增 `source_conversation_title`。
- 设置页长期记忆卡片新增“来源会话”区域。
- 点击“打开来源”会关闭设置弹窗并切换到来源会话。

## 当前边界

- 当前不是向量检索。
- 当前不是自动长期记忆，模型只提供候选，仍由用户确认保存。
- 当前不是全历史扫描，只从当前会话近期消息提取候选。
- 当前去重/冲突检测是规则级，不是 embedding 语义级。
- 来源追踪已经有字段，也已支持来源会话跳转，但还没有做来源消息级高亮定位。

## 下一步建议

- 做来源消息级定位与高亮。
- 做 tokenizer 级预算与摘要质量观测。
- 做缓存友好型 prompt 结构。
- 后续再升级语义级记忆去重。

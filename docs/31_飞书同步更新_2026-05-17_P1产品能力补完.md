# 飞书同步更新：P1 产品能力补完

## 本次新增

### 1. 会话分享

- 新增 `conversation_shares` 表。
- 支持私有只读分享链接。
- 支持生成、启用、关闭、撤销分享。
- 支持设置过期天数。
- 新增 `/share/[token]` 只读分享页。

### 2. 设置面板继续细化

- 设置页新增“隐私与导出”分区。
- 模型服务、生成参数、上下文、长期记忆、系统提示、Prompt 模板、外观继续按二级菜单管理。
- 分享和导出相关能力从会话菜单进入，同时在设置页提供说明入口。

### 3. 消息级定位

- 长期记忆来源支持跳转回来源会话。
- 如果来源记忆带有 `source_message_ids`，前端会滚动并高亮来源消息。

### 4. Prompt 模板增强

- `prompt_templates` 新增 `category` 和 `variables` 字段。
- 前端支持模板分类、变量占位符、变量填充、模板搜索。
- 支持快捷插入到全局 System Prompt。
- 支持显式应用到全局或指定工作区 System Prompt。

### 5. 会话导出增强

- 导出接口支持 `message_ids`、`include_attachments`、`include_context`、`as_zip` 参数。
- 前端新增导出选项弹窗。
- 支持 Markdown / JSON / ZIP。
- ZIP 可包含附件文件和会话元数据。

### 6. 工作区增强

- 新增 `project_files` 表。
- 支持工作区文件库：上传并归档到当前工作区。
- 支持项目统计：会话数、消息数、文件数、模板数、文件总量。

## 验证

- 后端 `python -m compileall backend/app` 通过。
- 前端 `npm run lint` 通过。
- 前端 `npm run build` 通过。

# 2026-05-11 更新：长期记忆 MVP

## 本次完成

- 完成长期记忆 MVP v1。
- 用户可以在设置面板手动新增、启用、停用、删除长期记忆。
- 长期记忆按用户隔离存储，不跨用户共享。
- 聊天请求会在 `system_prompt` 后、会话滚动摘要前注入启用的长期记忆。
- 上下文诊断面板新增长期记忆观测字段：
  - 长期记忆是否启用
  - 本轮是否注入长期记忆
  - 长期记忆条数
  - 长期记忆字符数

## 后端变化

- 新增 `user_memories` 表。
- 新增模型、schema、repository、service：
  - `UserMemory`
  - `UserMemoryCreate / UserMemoryUpdate / UserMemoryResponse`
  - `UserMemoryRepository`
  - `MemoryService`
- 新增 API：
  - `GET /api/memories`
  - `POST /api/memories`
  - `PATCH /api/memories/{id}`
  - `DELETE /api/memories/{id}`
- 用户设置新增：
  - `memory_enabled`
  - `memory_max_chars`

## 前端变化

- 设置面板新增“长期记忆”区域。
- 支持 4 类记忆：
  - 用户偏好
  - 项目背景
  - 重要事实
  - 长期指令
- 支持长期记忆开关与字符预算配置。

## 当前边界

- 第一版只做手动记忆，暂不做模型自动写入。
- 暂不做记忆冲突检测和来源追踪。
- 暂不做向量化长期记忆库。

## 下一步建议

- 做“模型建议记忆”：模型从对话里提取候选记忆，由用户确认后保存。
- 增加记忆去重和冲突检测。
- 将 Artifact Memory 与附件索引化能力结合。

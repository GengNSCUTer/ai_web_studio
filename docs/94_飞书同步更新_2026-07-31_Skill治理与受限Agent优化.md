# 2026-07-31：Skill 治理、受限 Agent 与上下文优化

本轮将产品边界进一步收口为个人本地知识库工作平台，重点是文档整理、检索、研究、审阅和可追溯的低风险辅助操作。支付、邮件、外部发布、任意外部 HTTP 写入、Bash、Shell、SQL、删除文件和任意本机文件写入均不纳入 Tool Catalog；文件修改仍使用 PatchDraft、用户确认、one-time continuation 和 FileRevision CAS。

参考 ReAct 文档后，项目吸收了 Think-Act-Observe、显式状态机、停止条件、取消传播、事件流和可观测性，但不采用代码代理的 Bash、自由写文件和 50 步循环。同步 Chat 继续最多两轮；长任务仅允许低风险只读 Skill 进入可恢复 Durable Tool Run。

Skill 当前为项目内置审核 Manifest。安装锁定版本和 manifest digest，支持显式升级/回滚；`repository_attestation` 仅是仓库内审核标记，不是第三方密码学签名。系统推荐 Skill 只给建议，必须由用户确认激活，不能自动安装或静默扩大权限。第三方市场待可信发布者密钥、detached signature、隔离拉取、兼容性测试、安全审核和回滚审计具备后再评估。

新增 Skill/Tool Gold Set 与离线评估接口，覆盖 Skill 推荐 Recall@3、Tool Recall、Planner 选择正确率、参数正确率、任务成功率和可选 p50 延迟。Durable Skill 增加 allowlist 二次校验、DLQ、受控重放、缺失 Outbox 对账和租约告警。

上下文模板升级为分层预算：`conversation_summary`、`long_term_memory`、`attachment_context`、`external_context`、`knowledge_context` 按优先级整体裁剪，再压缩剩余证据、裁剪旧历史，最后才处理当前问题。稳定前缀保持 cache-friendly 布局，但没有声称已接入 OpenAI/Anthropic Prompt Cache。

验证：后端 `compileall` 通过，单元测试 `279 tests, 3 skipped, OK`；前端 ESLint 与 production build 通过，`git diff --check` 通过。真实 Skill E2E 已走通显式选择、受限 Planner、Tavily、最终回答落库和 Trace。

# 2026-06-09 更新：Embedding 维度只读化

本次根据知识库模型配置讨论，对 Embedding 维度做了设计修正：Embedding 维度不再作为用户可手动调整的参数，而是由所选 Embedding 模型自动确定。

## 变更内容

- 设置中心“知识库模型”页签中，`Embedding 维度` 改为只读展示。
- 新建知识库弹窗中，`Embedding 维度` 改为只读展示。
- 选择常见 Embedding 模型时，前端自动推导维度：
  - `Qwen/Qwen3-Embedding-8B` -> `4096`
  - `Qwen/Qwen3-Embedding-4B` -> `2560`
  - `Qwen/Qwen3-Embedding-0.6B` -> `1024`
  - `BAAI/bge-m3` / `bge-large` -> `1024`
  - `netease-youdao/bce-embedding-base_v1` -> `768`
- 后端新增 `knowledge_model_metadata.infer_embedding_dimensions()`，在两个入口做保护：
  - 保存用户知识库模型设置时，已知模型会覆盖错误传入的维度。
  - 创建知识库时，已知模型会覆盖错误传入的维度。

## 设计边界

- `embedding_dimensions` 仍然保存在 `user_settings` 和 `knowledge_bases` 中，但它的身份是“索引元数据 / 校验字段”，不是用户调参项。
- 未知自定义 Embedding 模型暂沿用当前默认 / 传入维度，后续 RAG-3 索引执行时必须通过实际 embedding 返回向量长度做最终校验。
- 创建索引后如果更换 Embedding 模型导致维度变化，必须提示重建索引。

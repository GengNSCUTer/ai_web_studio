# 2026-06-10 RAG-5 聊天知识库接入

本次完成 `RAG-5` 第一版最小闭环：知识库已经可以在智能问答台中作为可选上下文来源使用。

## 已完成

- `/chat` 页面并行加载当前用户的知识库列表。
- 输入区新增知识库选择器：
  - 默认“不使用知识库”。
  - 选择知识库后，本轮聊天启用知识库检索。
  - 未选择时不触发知识库检索。
- 三条聊天链路均支持知识库：
  - 新发送消息。
  - 重新生成最后一条回答。
  - 编辑上一条用户消息并重新回答。
- 后端新增 `KnowledgeContextService`：
  - 校验知识库归属。
  - 检查知识库是否已生成 chunks。
  - 调用 FAISS 向量检索和可选 rerank。
  - 将召回 chunks 格式化为 `[KB1]`、`[KB2]` 等知识库片段。
  - 知识库不存在、未索引或检索失败时只产生上下文提示，不让整轮聊天失败。
- `ContextPromptBuilder` 新增独立 `knowledge_context` prompt 层：
  - 与联网搜索、附件片段、长期记忆分离。
  - 诊断字段新增 `prompt_knowledge_context_injected`。
- 回答来源卡片支持 `source_type=knowledge`：
  - 展示知识库名、文档名、chunk index、排序来源、vector/rerank 分数和片段预览。
- 上下文诊断面板新增知识库指标：
  - 是否启用知识库检索。
  - 知识库名称。
  - 总 chunk、召回 chunk、注入 chunk。
  - 知识库上下文字符数 / token 数。
  - rerank 是否启用 / 使用。
  - prompt 是否注入知识库层。

## 当前链路

```text
用户选择知识库并提问
-> 前端发送 knowledgeBaseId
-> Next.js proxy 转换为 knowledge_base_id
-> ChatExecutionService / ChatContextAssemblyService
-> KnowledgeContextService
-> KnowledgeIndexService.retrieve_async
-> FAISS vector search + optional rerank
-> prompt 注入【知识库片段】
-> 模型回答
-> 来源面板展示知识库引用
```

## 当前边界

- 只支持单知识库选择。
- 还没有多知识库同时检索。
- 还没有点击来源定位到文档 Markdown/chunk。
- 还没有知识库检索日志持久化。
- 还没有 Hybrid Search / BM25 / RRF / Parent-Child / Metadata Filter。

## 后续建议

1. `RAG-5.5`：知识库来源点击定位，打开文档预览并高亮 chunk。
2. `RAG-5.6`：知识库检索日志持久化，保存 query、候选 chunks、rerank、注入片段和引用。
3. `RAG-6`：多知识库检索、Hybrid/BM25/RRF、Parent-Child、Metadata Filter 和检索评测。

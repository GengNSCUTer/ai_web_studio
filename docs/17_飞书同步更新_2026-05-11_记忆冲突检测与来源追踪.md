# 2026-05-11 更新：记忆冲突检测与来源追踪

## 本次完成

- 为模型建议记忆增加规则级去重和冲突检测。
- 为长期记忆增加来源追踪字段。
- 前端候选记忆卡片展示风险标签：
  - 建议保存
  - 可能重复
  - 可能冲突

## 后端变化

- `user_memories` 新增字段：
  - `source_conversation_id`
  - `source_message_ids`
  - `confidence`
- 启动时自动迁移旧表结构。
- `POST /api/memories/suggest` 返回候选记忆时新增：
  - `duplicate_memory_id`
  - `conflict_memory_id`
  - `risk_level`
  - `risk_reason`
  - `source_conversation_id`
  - `source_message_ids`
  - `confidence`

## 风险检测规则

- 同类型 + 内容高度相似：标记为 `duplicate`
- 同类型 + 标题相近但内容差异较大：标记为 `conflict`
- 无明显风险：标记为 `safe`

## 前端变化

- 候选记忆卡片显示风险标签。
- 候选记忆卡片显示置信度。
- 保存候选时写入来源会话、来源消息和置信度。

## 当前边界

- 当前仍是规则级相似度检测，不是 embedding 语义去重。
- 暂不做自动合并已有记忆。
- 暂不做记忆版本历史。

## 下一步建议

- 做缓存友好型 prompt 结构。
- 或继续做 tokenizer 级预算与摘要质量观测。
- 后续再升级为语义级记忆去重。

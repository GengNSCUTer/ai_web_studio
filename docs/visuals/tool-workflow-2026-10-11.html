公开资料研究

用 Tavily / Exa 搜索，Exa 读公开网页，再整理带来源的简报。只取得摘录时说明读取范围。

技术文档查证

Context7 定位真实库 ID，再查询文档正文。库简介不能替代 API 行为的证据。

项目文档工作

列文件、定向/分页搜索、分段读取、起草。现有文本修改受项目权限与版本保护。

地图与出行查询

地理编码、天气、距离、驾车/步行/公交路线、关键词与周边地点查询。

后台结果与审计

查看 Run、步骤和产物，按需读取产物，下载脱敏 JSONL；失败任务受控重放。

扩展 MCP / Skill

新工具通过输入、结果映射、质量规则和样例审核后接入；Skill 推荐需用户激活，不能静默扩权。

知识库问答走独立 RAG 检索链，为同一回答补充证据；当前 20 个 Tool 中没有单独的“RAG 检索工具”。文档起草使用现有文件工具，不代表已开放新建/删除任意文件。

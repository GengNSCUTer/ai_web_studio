# 2026-05-11 更新：缓存友好型 Prompt 结构治理

## 本次完成

- 新增 `ContextPromptBuilder`，把聊天链路中的 Prompt 拼装逻辑从 `chat.py` 抽离到独立服务。
- 固定模型输入上下文层级，减少后续功能迭代时的 prompt 结构漂移。
- 调整上下文裁剪策略：先保留稳定 system 前缀，再裁剪最近历史消息。
- 前端上下文诊断面板新增 Prompt 结构相关指标。

## 固定上下文层级

当前 Prompt Builder 固定按以下顺序组织模型输入：

1. 稳定系统前缀：`AI Web Studio 上下文模板 v1`
2. 用户系统提示：设置里的 `system_prompt`
3. 长期记忆：启用的 `user_memories`
4. 会话滚动摘要：`conversations.context_summary`
5. 最近原始消息窗口
6. 当前轮图片附件
7. 当前轮文档解析文本

## 后端变化

- 新增 `backend/app/services/prompt_builder_service.py`。
- `chat.py` 不再直接负责图片、文件和历史消息的 Prompt 拼装。
- `ContextPromptBuilder` 统一输出 provider 可消费的 `messages`。
- `ContextPromptBuilder` 同时输出诊断字段：
  - `prompt_template_version`
  - `provider_template`
  - `model_family`
  - `prompt_layers`
  - `prompt_system_layers`
  - `prompt_history_messages`
  - `prompt_file_context_messages`
  - `prompt_image_messages`

## 前端变化

- 上下文诊断面板新增 Prompt 模板版本、Provider 模板、模型族、上下文层级和注入消息数量展示。

## 当前边界

- 当前完成的是“缓存友好型结构治理”，不是 provider 真实缓存 API 调用。
- 当前仍是字符级预算，不是 tokenizer 级精确预算。
- 当前只是 provider/model 模板入口，尚未为不同模型做深度差异化 prompt。
- 暂未做 prompt prefix hash、缓存命中率统计或成本统计。

## 下一步建议

- 做附件索引化与按需展开。
- 或做 tokenizer 级预算与摘要质量观测。
- 后续再补 prompt prefix hash 与缓存命中观测。

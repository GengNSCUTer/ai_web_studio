# RAG 收口与文档交付实施记录（2026-10-28）

## 执行顺序

1. 原文复核既有 Gold 标签，增加独立新题；开发集与新题分开。
2. 修正检索文本噪声并补充结构元数据；比较中英查询扩展和文档定位，收益以同标签对照为准。
3. 增加答案事实覆盖和拒答检查；完成真实 API、回归和浏览器测试。
4. 更新简历 v4 的 RAG 成果，明确数据规模、指标分母及证据来源。
5. 实现文档交付：从会话结果生成版本化 Markdown/DOCX 草稿、预览下载、受控保存工作区；已有文件修改复用 Diff/Approval/CAS。

## 边界

不启动本地模型，不改原论文数据与旧评测结果。不承诺新留出集代表线上分布，不根据留出集继续调参。产物不接受任意本机路径；下载和保存必须核验用户、项目和来源会话。首版不包含脚本市场或外部发布。保留现有未提交工作。
